# Project-Mesa
USB Forensic Station
### Core Components
- Raspberry Pi 3
- 32 GB MicroSD Card
- 5V/2.5A Micro-USB Power Supply
- USB Flash Drive
- 128GB External SSD
- Powered USB Hub

### Optional Components
- Raspberry Pi Case
- OLED Screen
- LEDs and Push Buttons

### Raspberry Pi OS Lite (32-bit)
`sudo apt update`
`sudo apt install -y gddrescue sleuthkit yara`
